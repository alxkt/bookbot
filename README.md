# BookBot

BookBot is a simple Python script that reads a text file and prints a report of the frequency of letters in the text, sorted from most to least frequent.

## Features

- Reads the content of a book file.
- Calculates the frequency of each letter in the text.
- Counts the total number of words in the text.
- Prints a sorted report of letter frequencies along with the total word count.

## Usage

To run the script, use the following command:

```sh
python3 main.py <path_to_book>
```

## Example
```sh
python3 main.py books/frankenstein.txt
```
